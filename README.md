- Sections for skills, experience and leadership, education, and certifications

## Run locally

1. Clone the repository:
   ```
   git clone https://github.com/Labiba-Rahman-Oroni/MY-Portfolio.git
   ```
2. Open the folder and double-click `index.html`, or run a local server:
   ```
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000` in your browser.

An internet connection is needed for the 3D scene to load.
