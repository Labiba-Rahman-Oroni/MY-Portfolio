# Labiba Rahman Oroni | Developer Portfolio

A responsive personal portfolio website with an interactive 3D hero section, showcasing my projects, skills, experience, and education.

**Live demo:** (add your GitHub Pages link here)

## Features
- Interactive 3D laptop scene in the hero section, built with Three.js
- Responsive design for desktop, tablet, and mobile
- Typing animation for my roles
- Project cards with a details popup and a link to each GitHub repository
- Sections for skills, experience and leadership, education, and certifications
- Contact form that opens your email app

## Built with
HTML5, CSS3, JavaScript (ES6), and Three.js (loaded from a CDN)

## Project structure
- `index.html` : page structure and content
- `style.css` : all styling
- `script.js` : skills and projects data, animations, form, and the 3D scene

## Run locally
Open the folder in VS Code and use the Live Server extension, or run:
```
python3 -m http.server 8000
```
Then visit http://localhost:8000. An internet connection is needed for the 3D scene.
